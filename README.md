# Noor Fashion
প্রতিষ্ঠান পরিচালনার অ্যাপ: কর্মী, হাজিরা ও ওভারটাইম, আয়-ব্যয়, মজুদ, মাসিক শিট, WhatsApp।

## APK ডাউনলোড
`main`-এ push করলে GitHub Actions স্বয়ংক্রিয়ভাবে Android APK বানায়।
- Releases পেজ থেকে সর্বশেষ `NoorFashion.apk` ডাউনলোড করুন।
- ফোনে ইনস্টলের সময় "Unknown sources / এই উৎস থেকে ইনস্টল" অনুমতি দিন।
- সব সংস্করণ একই কী দিয়ে সাইন করা, তাই নতুন APK পুরনোটির ওপর আপডেট হিসেবে ইনস্টল হবে।
